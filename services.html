Service Vertical 02 // Quality Assurance

Metrological & Third-Party Inspection (TPI)

Independent, authoritative third-party inspection services delivering proof of conformity with international standards, statutory regulations, and customer contractual specifications.

Engineering Design Review

Detailed technical scrutiny of engineering drawings, design calculations, ASME / API / ISO compliance standards, and welding/fabrication procedures before execution.

Stage & Final Inspection

Shop and on-site inspection covering raw material verification, in-process hold point inspections, dimension checks, hydro testing, and final pre-dispatch clearance.

Witnessing Performance Tests

Authoritative witness verification for load testing, hydrostatic pressure tests, electrical dielectric breakdown, dynamic balancing, and functional performance.

Strategic Value of Reva Phoenix Third-Party Inspection

  • ✔ Contractual Proof: Authoritative proof from an accredited body that your products comply with contractual and engineering tolerances.
  • ✔ Marketing & Export Advantage: Our third-party certificate serves as a powerful marketing asset for domestic bids and overseas shipments.
  • ✔ Turnaround & Piping Audits: Process piping inspection, plant turnaround assessment, and corrosion/erosion ultrasonic wall monitoring.
  • ✔ Personnel Qualification: Assessment and qualification of NDT Level I, II, and quality inspectors per ISO 9712 and ASNT SNT-TC-1A.
Service Vertical 03 // Precision Machine Tools

CNC Machine Calibration Services

Deploying the world-renowned Renishaw calibration instrument suite for CNC vertical machining centers (VMC), horizontal boring machines (HMC), turning centers, and gantry mills. We eliminate positioning errors, backlash, and geometric misalignments.

Renishaw XL-80 // Laser Interferometer

Linear Accuracy & Pitch Error Compensation

Delivers 0.001 ppm accuracy over ranges up to 40 meters. Measures linear positioning, pitch, yaw, straightness, and flatness, generating automated compensation tables for Fanuc, Siemens 840D, Heidenhain, and Mitsubishi CNC controls.

±0.5 µm/m Precision • 6-DOF Laser Metrology
Renishaw XR20-W // Rotary Axis System

4th & 5th Axis Rotary Calibration

Provides wireless rotary axis angular positioning accuracy to ±1 arc-second for A, B, and C rotary tables, trunnions, and tilting heads. Ensures multi-axis simultaneous machining accuracy on aerospace components.

±1 Arc-Sec • 360° Continuous Wireless Range
Renishaw QC20-W // Wireless Ballbar

Circularity & Dynamic Servo Diagnostics

Evaluates CNC machine dynamic performance in under 15 minutes. Quantifies circularity, squareness, reversal spikes, backlash, servo lag, and cyclic errors across XY, YZ, and ZX planes in accordance with ISO 230-4.

23 Machine Errors • ISO 230-4 Diagnostic Standard

Service Vertical 07 // Oil & Gas Specialized Metrology

API Gauges Calibration

High-precision thread metrology for American Petroleum Institute (API) specified thread gauges. Traceable to certified API Reference Master Gauges, ensuring the structural and pressure integrity of drilling connections, casing, and tubing.

Full Compliance with API Standards

  • API Spec 5B: Threading, Gauging, and Inspection of Casing, Tubing, and Line Pipe Threads.
  • API Spec 7-2: Rotary Shouldered Thread Connections (NC, Regular, Full Hole, Internal Flush).
  • API Spec 11B: Sucker Rods and Coupling Thread Gauges.

Parameters calibrated include: Lead, Taper, Flank Angle, Pitch Diameter, Standoff, and Full Thread Form Verification using master measuring equipment in environmentally controlled dark-room labs.

Master vs. Working Gauge Capability

EXTERNAL THREADS

API Ring Gauges

Calibrated for pin thread inspection on casing, tubing, and drill pipe pins.

INTERNAL THREADS

API Plug Gauges

Calibrated for box connections, couplings, and downhole tool bodies.

Service Vertical 08 // Non-Destructive Testing Metrology

NDT Equipment Calibration

Precision calibration of Non-Destructive Testing (NDT) electronic instruments and physical reference blocks. Ensuring flaw detection accuracy, magnetic field integrity, and acoustic thickness measurement reliability.

Ultrasonic Testing (UT)

Horizontal & vertical linearity, time-base accuracy, gain attenuator linearity, and sound velocity calibration on Ultrasonic Flaw Detectors and Ultrasonic Thickness Gauges.

Magnetic Particle Testing (MPT)

Dead weight lift force verification (4.5 kg AC / 18.1 kg DC) for Electromagnetic Yokes, and magnetic field intensity verification for Gauss Meters.

NDT Calibration Blocks

Dimensional, acoustic velocity, and slot depth calibration for V1 (IIW Type 1), V2 (IIW Type 2), DAC, Step Wedge, and ASTM Reference Test Blocks.
